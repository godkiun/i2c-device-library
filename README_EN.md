# I2C Device Library Collection 📟

Multi-platform C++/C library collection for I2C sensors, displays, and peripherals supporting AVR, Arduino, PIC18, ESP32, STM32, and MSP430.

---

## 🖥️ Supported Platforms

* **Arduino**
* **ESP32 (ESP-IDF)**
* **Microchip PIC18**
* **STM32**
* **MSP430**
* **Raspberry Pi (bcm2835)**
* **nRF51 / EFM32**
