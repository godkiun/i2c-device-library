# I2C Device Library Collection 📟

Colección multiplataforma de librerías en C++ y C para sensores, pantallas y periféricos I2C compatibles con AVR, Arduino, PIC18, ESP32, STM32 y MSP430.

---

## 🖥️ Plataformas Soportadas

* **Arduino**
* **ESP32 (ESP-IDF)**
* **Microchip PIC18**
* **STM32**
* **MSP430**
* **Raspberry Pi (bcm2835)**
* **nRF51 / EFM32**
